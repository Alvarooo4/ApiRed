# Modelo de Problema

Modelado del problema expuesto en [HU001](historias-usuario.md#hu001-no-sé-si-un-campo-tiene-las-condiciones-climáticas-adecuadas-antes-de-trasladar-mis-colmenas) atendiendo a la metodología _DDD_ y usando el lenguaje ubicuo definido en [docs/dominio.md](dominio.md).

## Términos a modelar:
Ruta, Ubicación, Coordenadas, Desplazamiento, Clima Local, Fenómenos, Registro, Variables Meteorológicas -> solo se considera la temperatura -> Temperatura, Flora, Flor, Heurística de Floración.

## Quedan sin mencionar del lenguaje ubicuo:
Datos Meteorológicos, Gastos, Ubicación Geográfica, Apicultor, Dinero, Trashumancia, Tiempo de desplazamiento, Cargar, Camión, Viabilidad Floral, Colmenar, Colmena, Abejas, Alimento.
